# 🎮 RetroCore32 (ESP32 Atari-Style Arcade)

A mini Atari-inspired arcade console built using ESP32.  
This project recreates retro-style gameplay with simple hardware components, combining graphics, controls, and sound into one compact embedded system.

---

## 🚀 Features

- 🎮 Joystick-based game control  
- 🔘 Multiple buttons for interaction  
- 📺 OLED display for game visuals  
- 🔊 Dual buzzer sound effects  
- 💡 LED indicators for feedback  
- ⚡ Real-time input handling using ESP32  

---

## 🧠 Concept

The goal of this project is to simulate a classic arcade experience (similar to early Atari games) using low-level embedded programming.  
It focuses on integrating multiple inputs and outputs into a responsive and interactive system.

---

## 🛠️ Hardware Used

- ESP32  
- OLED Display (I2C)  
- Joystick Module  
- Push Buttons  
- LEDs + Resistors  
- Buzzers  
- Breadboard & jumper wires  

---

## ⚙️ How It Works

- The joystick controls movement within the game  
- Buttons trigger actions (e.g., start, select, interact)  
- The OLED screen renders game elements in real time  
- Buzzers provide audio feedback for events  
- LEDs indicate system states or actions
